# Ego Hygiene

Ego Hygiene builds open-source tools, knowledge systems, automation, and
AI-powered workflows for human flourishing.

Each repository owns a focused capability, its roadmap and its delivery
evidence. Implementation and release readiness vary across the portfolio;
check the owning repository's current records for supported behavior.

## Explore the foundations

| Repository | What it owns |
| --- | --- |
| [Hygiene](https://github.com/egohygiene/hygiene) | Ecosystem architecture, policy and canonical organization strategy. |
| [Aether](https://github.com/egohygiene/aether) | Reusable AI specifications, skills and agent guidance. |
| [Holon](https://github.com/egohygiene/holon) | Repository blueprints and governed materialization. |
| [Empathy](https://github.com/egohygiene/empathy) | Golden-consumer baseline and integration evidence. |

The [proposed organization roadmap](https://github.com/egohygiene/hygiene/blob/main/organization/ROADMAP.md)
describes current, next, later and optional directions. Repository roadmaps,
issues and releases retain their own scope and acceptance evidence.

## Follow the work

Start with the [organization home](https://github.com/egohygiene/.github),
then follow the [repository dashboard directory](https://github.com/egohygiene/.github/blob/main/docs/intelligence/repositories.md).

| Find | Go to |
| --- | --- |
| Organization overview | [Intelligence](https://egohygiene.github.io/.github/intelligence/) |
| Audit evidence | [Audits](https://egohygiene.github.io/.github/audits/) |
| Architecture reviews | [Sanity](https://egohygiene.github.io/.github/sanity/) |
| Current delivery work | [Completion roadmap](https://github.com/egohygiene/.github/blob/main/docs/intelligence/DELIVERY_ROADMAP.md) |
| Cross-repository coordination | [Organization issues](https://github.com/egohygiene/.github/issues) |

Each repository owns its detailed dashboard and source evidence. This organization
home connects the views and makes the next work visible. The links above use
the live organization project Pages site; the website remains the UI compositor
and other repositories retain their publishers.
