# Getting help

Start with the receiving repository's README and local support instructions.
Search existing issues for the same problem. If an enabled repository Discussion
category fits, use it; otherwise use that repository's issue tracker with a
sanitized description, expected behavior, actual behavior and relevant versions.

If ownership is unclear, consult the
[organization routing guide](https://github.com/egohygiene/.github/blob/main/docs/issue-routing.md)
and the organization work forms in this repository. Keep implementation work
with its owning repository and link cross-repository dependencies.

Do not include tokens, private exports or personal data in a support request.
Use the [security reporting guidance](https://github.com/egohygiene/.github/blob/main/SECURITY.md)
for sensitive vulnerabilities. Responses depend on maintainer availability;
this fallback establishes no response deadline or support entitlement.
