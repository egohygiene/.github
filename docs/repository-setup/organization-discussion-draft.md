# 🧠 Start here: organization questions, ideas and coordination

**Draft only.** No category has been selected and this discussion has not been
posted. Review the repository's current visibility and purpose before use.

This `.github` repository is Ego Hygiene's organization entry point. It holds
shared community defaults, contribution and issue-routing guidance, and links
to repository-owned work and Intelligence dashboards.

Use this space for questions about where a capability belongs, ideas that span
repositories, and feedback on the shared contributor experience. If you already
know the implementing repository, start there. Once a proposal has a concrete
owner and outcome, link its implementation issue rather than keeping a second
checklist in the discussion.

Useful starting points:

- [Organization overview](https://github.com/egohygiene/.github)
- [Issue routing](https://github.com/egohygiene/.github/blob/main/docs/issue-routing.md)
- [Repository directory](https://github.com/egohygiene/.github/blob/main/docs/intelligence/repositories.md)

For a useful question or idea, describe your goal, the repository or capability
involved, what you have tried, and the decision or help you need. Keep credentials,
private repository details, personal data and sensitive reports out of public
threads. Use the owning repository's private reporting channel where appropriate.
