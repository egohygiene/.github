## Organization roadmap reference

[`organization-roadmap-reference.svg`](organization-roadmap-reference.svg) is a presentation-oriented mock created from the live planning context on 2026-09-16.

It intentionally compresses the current direction into two understandable lanes:

1. **Reusable engine** — established foundations → Repository Intelligence → Organization Intelligence → continuous control loop.
2. **Creative proof** — Flow-suite hardening → orchestration proof → real comic/media releases → reuse by Incompris LLC and future creative products.

The mock exists to preserve a clear visual north star while the canonical organization-roadmap contract and read model are completed.

## Design constraints carried forward

- orient before showing detail;
- keep active, next, later, blocked, stale, unknown, deferred, optional, and complete distinct;
- show safe parallel lanes instead of a single fake linear backlog;
- avoid naive issue-count percentages;
- deep-link visual nodes to canonical roadmap/evidence and GitHub execution work;
- keep later/optional work collapsed by default;
- preserve a text-equivalent hierarchy for accessibility;
- treat visual artifacts as disposable projections that can be regenerated from canonical evidence.
